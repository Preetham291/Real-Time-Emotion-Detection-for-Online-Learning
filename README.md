# Real-Time Emotion Detection for Online Learning

A web-based instructor dashboard that analyzes students' webcam feeds in real time using DeepFace. Visualizes engagement, emotion timeline, and session summaries—helping educators monitor focus, confusion, and emotional feedback live.

---

## 🚀 Features

- **Live emotion analysis:** Uses students' webcam data to infer emotions (focused, happy, confused, bored, etc).
- **Instructor dashboard:** Summarizes engagement with real-time graphs and timelines.
- **Easy setup:** Pure Python backend (Flask), modern UI, and no frontend experience required.

---

## 🛠️ Technology Stack

- **Backend:** Python, Flask, Flask-SocketIO, DeepFace, OpenCV
- **Frontend:** HTML, Tailwind CSS, Chart.js, JavaScript
- **Live communication:** WebSockets (via Flask-SocketIO)
